Signatures e-mail

Une signature sobre pour chacun, et une pour l’équipe. Clique sur « Copier », puis colle-la dans les réglages de signature de ta messagerie.

Dans Outlook

  1. Outlook sur le web : roue dentée → Courrier → Composer et répondre → Signature électronique → colle (Ctrl+V) → Enregistrer.
  2. Outlook sur Windows : Fichier → Options → Courrier → Signatures → Nouveau → colle dans la zone → OK.
  3. Gmail : roue dentée → Voir tous les paramètres → Signature → Créer → colle → Enregistrer en bas de la page.
